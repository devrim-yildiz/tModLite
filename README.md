# tModLite

**In development — no public release yet.**

tModLite is a lightweight modding runtime for Terraria Mobile. The goal is to
make custom items, crafting recipes, bosses, biomes and other content easy to
create with Lua, with menus that feel at home inside Terraria.

## Development status

Development and device testing are currently focused on iOS. Work covers native
mod-management menus, Lua mod authoring, custom items and recipes, boss behavior,
and runtime reliability. Broader content support and other platforms are planned.

This repository contains **earlier prototype code**. The current runtime, Lua SDK,
example mods and development builds are being developed privately and **have not
been uploaded here**. They will be published when ready; there is no public
installation package available yet.

## Community

tModLite is an independent project and is not affiliated with Re-Logic or
505 Games. It is a separate runtime; existing desktop tModLoader mods cannot be
loaded directly.
